# Arduino Parking Assistant

An embedded parking assistance system using an Arduino Uno, ultrasonic sensor, OLED display, RGB LED, and buzzer.

## Features

- Real-time distance measurement
- OLED display
- Parking state detection
- RGB LED warnings
- Adjustable buzzer
- Sensor error handling
- Modular C++ files

## Hardware

- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- SSD1306 OLED Display
- RGB LED
- Piezo Buzzer
- Push Button

## States

- SAFE
- CLOSE
- TOO_CLOSE
- COLLISION_WARNING
- ERROR
